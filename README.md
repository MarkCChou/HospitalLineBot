# HospitalLineBot

**HospitalLineBot** is a LINE Bot built with ASP.NET Core that allows users to interact with hospital services via messaging.

## Project Structure

- `HospitalLineBot/` – The main ASP.NET Core project that implements LINE Bot functionality and connects to the LINE Messaging API.

## Features

- Built with ASP.NET Core and C#.
- Uses webhook to establish a connection between the LINE Bot and LINE platform.
- Integrated with LINE Messaging API via Channel Access Token.
- Includes broadcast functionality to send text, stickers, images, videos, and location messages to users.
